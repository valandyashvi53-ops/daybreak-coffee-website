# daybreak-coffee-website
A modern, responsive coffee shop website built using HTML, CSS, and JavaScript. Features include a home page, about section, coffee menu, image gallery, brewing guide, customer reviews, and contact form.
Daybreak Coffee ☕

A modern and responsive coffee shop website designed to showcase coffee products, brewing styles, and the cozy atmosphere of a neighborhood café.

Features
Responsive design for desktop and mobile
Modern coffee shop landing page
Coffee menu and product cards
Image gallery
Coffee brewing guide
Customer reviews section
Contact form UI

Smooth hover effects and elegant styling
